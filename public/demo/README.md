# Fictional event demo photos

Four images generated with ChatGPT's built-in image generation on 12 November 2026. No real participant photos or identities were supplied. The CSV contains invented names and example.com addresses. These are independent synthetic scenes, not evidence of a real event or a reliable cross-photo identity set.

The assets are bundled with the app and loaded from its own origin only when the visitor chooses the example. No runtime AI service or image host is involved. Existing local projects are not automatically replaced. To try the new set without losing work, use a separate browser profile; keep any originals and export a backup before resetting a project.

## Suggested walkthrough

- Workshop: practise assigning a photo to a few fictional recipients.
- Coffee: practise assigning another small-group photo.
- Group: use the all-participants action.
- Venue: use it as a common photo for everyone.

Names are arbitrary demonstration assignments, not identification of people in these synthetic pictures. Do not send the demo drafts as real event follow-ups.
